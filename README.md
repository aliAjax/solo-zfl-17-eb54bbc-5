# 多卷胶片修复核对台

给放映员和档案员用的**纯离线**网页工具：管理多卷胶片、记录每个片段的颜色偏移与破损处理结论、跨卷重组后自动核对。直接双击打开 `index.html` 即可，不需要联网、不依赖任何服务器，数据只保存在本机浏览器的 localStorage 中。

## 功能

### 多卷管理
- 胶片卷可**新建、切换、重命名、整卷复制、删除**（最后一卷不可删）。
- 片段可在同卷内**拖拽排序**或用按钮上下移，也可编辑、删除。
- 勾选片段后可**跨卷移动或复制**，支持批量；同一次操作可混合处理。

### 录入校验（非法输入只提示、绝不入库）
- 片段**编号忽略大小写后在同卷内唯一**（A-01 与 a-01 视为重号）。
- **时长必须为正数**（秒）。
- **颜色偏移与破损分开记录**：颜色有类型（正常/偏红/偏青/偏黄/偏蓝/褪色）和独立的 RGB 偏移量（-100~100）；破损另有类型（划痕、齿孔破损、接片松动、霉斑、脆裂、画面缺损）。
- **破损片段必须写明处理结论**（保留原片/数字修复/物理修补/重接/跳过该段/待复核），否则不能保存，列表和右侧提醒会持续标红。

### 跨卷冲突处理
- 移动/复制到目标卷时，忽略大小写检测编号冲突，弹窗逐段列出冲突对象，可分别选择：
  - **自动改名后加入**（默认给出跳过已占用编号的新编号，可手改，执行时二次校验）
  - **跳过该片段**（移动时留在源卷）
  - **覆盖目标卷同号片段**
- 可整批取消，取消后数据不变。

### 跨卷重组核对（四个检查，均附原因说明）
在「跨卷重组核对」页先**设为重组前基线**，之后重组会自动核对（也可手动重新核对）：
1. **编号冲突**：同卷重号（硬错误）与跨卷同号（取错片盒风险提醒）。
2. **丢失片段**：按片段 id 追踪基线中的片段是否还在；自动改名不误报，删除/覆盖会点名并解释。
3. **总时长核对**：逐卷对比 + 全局守恒说明（纯移动总量不变，复制增加，删除/覆盖减少）。
4. **颜色断层**：按放映顺序计算相邻片段 RGB 偏移的均方根色差，超过可调阈值（默认 25）即报告，提示画面跳变。

### 撤销 / 重做、备份、导出
- 所有编辑操作可**撤销/重做**（按钮或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z），含跨卷移动、删除、恢复备份。
- **本机快照**：手动保存（最近 5 个），一键恢复。
- **JSON 完整备份**导出/恢复：恢复前严格校验，整份不通过即拒绝并列出全部原因，**当前清单不会被改动**：
  - 损坏的 JSON、错误的根结构（数组 / null / 缺 reels）
  - 未知/恶意字段（白名单制，含 `__proto__` 等）、`<script>` / `onerror=` 等注入内容、控制字符
  - **内部身份串（卷 id / 片段 id / activeReelId）必须符合安全格式** `^[A-Za-z0-9_-]{6,64}$`：含引号、尖括号、空格、`javascript:` 等的伪造 id 一律拒绝，防止闭合 HTML 属性插入 `<img onerror>` 等标记；渲染层对所有 id 属性另做转义（纵深防御）
  - 编号重复、时长非正数、破损缺结论、枚举非法、id 重复或悬空等
- **本机旧记录兼容**：启动读取本机数据时自动修复身份串——不安全身份串每次出现都换新；格式安全但被多条记录共用时，**首条保留原值，其后每次出现各获得一个独立且稳定的新值**；分配表以主数据为准建立，基线、快照复用同一张表，跨记录引用继续对应（核对不误报丢失）。修复后的数据通过完整校验才回写存储。
- **现场保护模式**：原始存储 JSON 损坏、无法迁移或修复后仍未通过校验时，页面进入只读保护的临时工作台：顶部红色横幅说明原因，**任何编辑、快照、导出和自动保存都不会覆盖原始存储**；可一键「下载现场原始数据」（含三处存储的原始字符串与失败原因）交维护人员排查，也可在二次确认后放弃损坏记录并重建，或直接恢复一份有效备份退出现场保护。
- **清单导出**：TXT（人类阅读，含每卷与合计）、CSV（Excel 可打开，带 BOM）、JSON（完整备份）。导出前同样校验，非法数据不写出。

### 实时与持久化
- 筛选（关键词 / 颜色 / 破损状态，含“破损待结论”）、统计、提醒**随每次编辑即时更新**。
- 数据、基线、快照自动持久化，**刷新页面不丢数据**；并自动迁移旧版（v1）单卷数据。

## 文件
- `index.html` / `styles.css` / `app.js`：应用本体，无外部依赖。
- `e2e-check.js`：Playwright 端到端走查脚本（114 项断言，覆盖多卷编辑、冲突三种处理、审计四查、撤销重做、三种导出、异常/恶意输入拒绝、快照、刷新保留、拖拽排序）。
- `e2e-id-security.js`：身份串安全专项复测（64 项断言）：外部备份中恶意卷/片段/activeReelId 必须被拒绝且无 `<img>` 插入、无事件执行、数据不变；本机旧记录中的恶意 id 启动自动清洗且主数据/基线/快照引用同步；清洗后切换卷、编辑、跨卷搬运、冲突改名、撤销重做、刷新保存均正常；合法自定义 id 原样保留。

## 运行端到端走查
```bash
npm i playwright && npx playwright install chromium
node e2e-check.js          # 主流程 114 项
node e2e-id-security.js    # 身份串注入与清洗 64 项
```
导出的样例文件在 `test-output/`。
